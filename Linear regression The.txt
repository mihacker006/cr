Dataset: Diabetes | 442 samples | 10 features
1. What is Regression?
Regression is a machine learning technique used to predict continuous numerical values.

Examples:
- House price prediction
- Temperature prediction
- Salary prediction
- Sales prediction
Regression predicts a number rather than a category.
2. What is Linear Regression?
Linear regression is a supervised machine learning algorithm that predicts a numerical output using a linear relationship between input and output.

Example:

Predicting house price based on area.

If the area increases, the house price may also increase.
3. What is Multiple Linear Regression?
Multiple linear regression predicts one output using two or more input features.

Example:

Predicting disease progression using:
- Age-related measurements
- BMI
- Blood pressure
- Other medical measurements
Formula
\[
Y=b_0+b_1X_1+b_2X_2+\cdots+b_nX_n
\]

Where:
- \(Y\) = predicted output
- \(b_0\) = intercept
- \(b_1,b_2,\ldots,b_n\) = coefficients
- \(X_1,X_2,\ldots,X_n\) = input features
4. What is a Coefficient?
A coefficient represents how much the predicted output changes when an input feature increases by one unit, assuming the other features remain constant.

Positive coefficient: The predicted output increases.

Negative coefficient: The predicted output decreases.
5. What is an Intercept?
The intercept is the predicted output when all input features are zero.

It is represented by \(b_0\).
6. What is Training Data?
Training data is the portion of the dataset used to teach the model.

The model learns the relationship between input features and output values.
7. What is Testing Data?
Testing data is used to check how well the trained model predicts unseen data.

Your experiment uses an 80:20 split.
- 80% training data
- 20% testing data
8. What is MSE?
MSE stands for Mean Squared Error.

It calculates the average squared difference between actual and predicted values.
\[
MSE=\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat y_i)^2
\]

Where:
- \(y_i\) = actual value
- \(\hat y_i\) = predicted value
- \(n\) = number of samples
Lower MSE means better predictions.
9. What is RMSE?
RMSE stands for Root Mean Squared Error.

It is the square root of MSE.
\[
RMSE=\sqrt{MSE}
\]

RMSE is easier to understand because it uses the same units as the target variable.
10. What is R² Score?
R² measures how well the model explains the variation in the target variable.
\[
R^2=1-\frac{SS_{\text{residual}}}{SS_{\text{total}}}
\]

Simple interpretation:
- R² = 1: Perfect prediction.
- R² = 0: No improvement over predicting the target mean.
- R² < 0: Worse than predicting the target mean.
Your experiment obtains approximately 0.45.

This means the model explains about 45% of the variation in disease progression.
11. What is Multicollinearity?
Multicollinearity happens when two or more input features are strongly related to each other.

Example:

Two medical measurements may contain similar information.

It can make individual regression coefficients unstable or difficult to interpret.

Your experiment observes strong relationships between some diabetes features.

Ridge regression in Experiment 5 helps address this problem.
